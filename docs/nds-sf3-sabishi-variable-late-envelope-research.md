# SF3 SABISHI: source-specific validation of variable tempo and late enable

This experiment exposes the existing bounded variable-tempo/late-enable/fitted
attack capability as `sf3-sabishi-variable-late-envelope`, using verified Japanese
`ssr3b`, sequence 33 `BGM_SABISHI`, and Japanese EXE6 Gregar. It adds a selector;
conversion, fit bounds and native driver/mixer behavior are unchanged.

The independent source comparison explains why this requires a new exact-ROM
check. SF2 SABISHI produces the same packed ROM/BPS as accepted SF1 SABISHI,
although source instrument/archive identifiers differ. SF3 uses different
instrument identifiers and generally one-tick-shorter note gates, with a different
source trace boundary on track 3. Its generated bytes differ. The original
SF3 note schedule and PCM are checked directly; no notes are replaced by the
SF1 schedule and no acceptance is transferred by song name.

## Source and automated evidence

The source is the registered `ssr3b.nds`; SDAT SHA-256 is
`bf986568be3b1b4bd0c7674694cd3b86641a266138df3271989a2f6fea240220`.
Eight tracks loop with period 3072 ticks. Track 3 first sounds at 528 and enables
fixed depth ten at 1440, using pitch/speed20/range1/delay0 thereafter. The six
source tempos are 40/65/70/75/90/100. The common native loop begins at 4512,
with joins at 7584 and 10656. Existing attack fitting maps attack100 to native74
within the unchanged RMS/max limits of 0.12/0.30. The ROM retains ten voices,
10512 Hz, fourteen raw PCM8 waves and +3.5 dB gain.

The pinned independent 180-second software source render matches 1,845 notes,
fourteen decoded waves, 25 tempo controls and six depth controls. Envelope checks
cover 1,845 note-on snapshots, 453,733 voice timer updates and 3,094 noninstant
attack updates. The late enable and modulation state-preservation checks pass;
this song provides no carried-positive-depth update coverage.

Natural native playback uses frontend Start at frames 180–190, then runs through
two common cycles: 8,197 frames to clock 10657, all fourteen samples, no clock
restart, header redirection or register/RAM injection. Nineteen independent
frame/clock windows cover all six tempos within 1.01 ticks. Read-only NOTE entry,
allocation and exit observations cover 1,400 actual allocations with zero rejected
notes. Across 8,198 frames to clock 10658, all 65,584 LFO track states match the
allocation-aware model. A fabricated rejection at an observed reset fails at
clock 1489. Handler bytes match the pinned original. Only track 3 modulates.

All 992 mapped notes, 114 keyed tone slots and fourteen waves match source-derived
pan, fitted ADSR, tuning and relocated raw PCM. The native title envelope check

Controlled effects 100/129 and three stop/native-restore/restart cycles pass;
these injected helper probes do not establish actual battle/map transitions.

Clock-aligned pitch diagnostics show about 6.13 cents RMS and 14.06 cents maximum
difference on track 3. Isolated mapped frequency error reaches about 1.26% for
these configurations. Neither diagnostic is a whole-song fidelity bound. The
thirty-second native preview peaks at 13443; its normalized A/B page covers the
initial late enable, not the later tempo dip or loop joins.
